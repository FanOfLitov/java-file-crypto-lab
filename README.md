# Лабораторная работа №3
## Разработка и программная реализация криптографических алгоритмов

### Цель работы

Изучение методов криптографической защиты данных и получение практических навыков программной реализации шифрования и дешифрования файлов.

### Задача

Разработать на языке Java программу, обеспечивающую шифрование и дешифрование файлов. Управление режимами работы программы осуществляется с использованием параметров командной строки. При запуске программы без параметров должна выводиться справочная информация. При отсутствии переданного пользователем ключа программа должна обеспечивать его генерацию.

### Теоретическая часть

Криптографическая защита информации применяется для предотвращения несанкционированного доступа к данным. Одним из основных механизмов криптографической защиты является шифрование, при котором исходные данные преобразуются в форму, недоступную для непосредственного чтения без знания соответствующего ключа.

В разработанной программе применяется симметричный алгоритм AES в режиме GCM. При симметричном шифровании один и тот же секретный ключ используется как для шифрования, так и для расшифрования данных.

Для формирования ключа AES из пароля пользователя применяется хеш-функция SHA-256. Для каждого процесса шифрования дополнительно генерируется случайный вектор инициализации IV длиной 12 байт.

Для генерации случайных значений используется класс `SecureRandom`.

### Ход работы

На первом этапе был создан Java-проект и реализована обработка аргументов командной строки.

При запуске программы без аргументов пользователю выводится справочная информация.

Для шифрования применяется команда:

`encrypt <input> <output> [password]`

Для дешифрования:

`decrypt <input> <output> <password>`

Основная криптографическая логика реализована в классе `Encryptor`.

Метод `encryptFile()` выполняет следующие действия:

1. Читает содержимое исходного файла.
2. Формирует ключ AES из переданного пароля.
3. Генерирует случайный IV.
4. Выполняет шифрование средствами `AES/GCM/NoPadding`.
5. Записывает IV и зашифрованные данные в выходной файл.

Метод `decryptFile()` выполняет обратную последовательность операций.

Для автоматической генерации пароля создан класс `KeyGenerator`. Генерируемый пароль имеет длину 16 символов и содержит прописные и строчные буквы, цифры и специальные символы.

Если пароль при выполнении команды `encrypt` не передан, программа генерирует его автоматически и выводит пользователю.


### Проверка работы программы
### Проверка работы программы

Для проверки работы программы был создан тестовый файл `test.txt`.

Исходный код программы был скомпилирован командой:

`javac Main.java Encryptor.java KeyGenerator.java`

После успешной компиляции было выполнено шифрование тестового файла с использованием заданного пароля:

`java Main encrypt test.txt test.enc MyPassword123!`

В результате программа вывела сообщение:

`File encrypted successfully`

и создала зашифрованный файл `test.enc`.

После этого было выполнено дешифрование:

`java Main decrypt test.enc restored.txt MyPassword123!`

В результате программа вывела сообщение:

`File decrypted successfully`

и создала файл `restored.txt`, содержащий восстановленные исходные данные.

Таким образом, была подтверждена корректная работа операций шифрования и дешифрования при использовании одного и того же пароля.
### Заключение

В ходе лабораторной работы была разработана Java-программа для шифрования и дешифрования файлов с использованием алгоритма AES в режиме GCM.

Программа поддерживает управление через параметры командной строки, вывод справочной информации, генерацию пароля при его отсутствии, шифрование и дешифрование произвольных файлов, а также обнаружение неверного ключа при расшифровании.

Поставленная задача выполнена.
